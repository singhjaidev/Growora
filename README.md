# Growora

**Better leads. Bigger opportunities.**

Growora is a business opportunity platform designed to help teams turn incoming enquiries into meaningful client conversations. It brings lead context, qualification, ownership, and next steps into one clear experience.

## About the project

Growora is being developed for agencies, consultants, property teams, and service businesses that want a more organised approach to managing opportunities.

The current development phase focuses on the homepage, visual design system, and interactive product experiences.

## Current highlights

- Responsive homepage with a signature navy colour palette
- Editorial typography and architectural imagery
- Interactive 3D lead journey
- Enquiry qualification previews
- Step-by-step workflow exploration
- Opportunity pipeline and business-specific content
- Pricing options and accessible FAQ interactions
- Scroll transitions and reduced-motion support

## Tech stack

- Next.js
- React
- TypeScript
- Three.js
- CSS Modules
